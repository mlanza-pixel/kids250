SPANISH AGENT ADVENTURE v2

Upload ALL contents of this folder to GitHub Pages (index.html at repository root).
250 default illustrated SVG placeholders are in images/defaults/.
To replace any image, save a JPG using the exact name from Image_Inventory_250.xlsx column G into images/custom/.
Example: images/custom/img_m1_1.jpg replaces the dog placeholder. If absent or broken, the default SVG displays.
The Excel spreadsheet is an editorial tracking tool; the app uses the filename as the link.
Spanish speech requires iPhone/iPad browser speech synthesis support and Spanish voice availability.
App works offline after files are cached, but first visit requires internet.
This is a prototype; validate on real devices before publishing to children.
